Installer l'aperçu

Télécharger l'installateur .exe · 180 Ko Toutes les versions

Le lien passe par ton dépôt GitHub privé : connecte-toi à GitHub dans ce navigateur si le téléchargement affiche « Not Found ».

  1. Lance l'installateur

    Il trouve Aseprite tout seul (version Steam ou installée), installe l'extension, l'aperçu (51 Mo, avec les données du jeu) et un raccourci « RPG Rogue Aperçu » sur le Bureau et dans le menu Démarrer.

  2. Connecte-le à GitHub, une seule fois

    Si GitHub CLI est déjà connecté sur ce PC, il s'en sert. Sinon, il te demande un jeton : clique sur son lien, choisis le dépôt RPG_Rogue_Art, permission Contents : Read-only, puis colle le jeton. Il est gardé chiffré sur ce PC.

  3. Relance Aseprite

    L'extension se charge au démarrage d'Aseprite. Elle se connecte toute seule à l'aperçu dès qu'il est ouvert.

  4. Ouvre « RPG Rogue Aperçu »

    Le raccourci vérifie s'il y a une nouvelle version, l'installe si besoin, puis ouvre la fenêtre. Mets-la sur ton 2e écran et passe en plein écran avec F11.

Windows peut afficher « Windows a protégé votre ordinateur »

L'installateur n'est pas signé. Clique sur « Informations complémentaires », puis sur « Exécuter quand même ».
