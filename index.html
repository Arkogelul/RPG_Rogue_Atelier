Connexion

Les graphismes et les références sont dans le dépôt privé RPG_Rogue_Art. Colle une clé GitHub (une fois par navigateur) :

  1. Créer une clé : Repository access → Only select repositories → RPG_Rogue_Art.
  2. Permissions → Contents : Read and write. Generate token, puis copier.

Aperçu en direct

Télécharger l'installateur Versions

  1. Lancer l'installateur. Si Windows bloque : « Informations complémentaires » → « Exécuter quand même ».
  2. S'il demande un jeton GitHub : suivre son lien (dépôt RPG_Rogue_Art, Contents : Read-only), coller le jeton.
  3. Relancer Aseprite.
  4. Ouvrir « RPG Rogue Aperçu » (Bureau). Il se met à jour tout seul.
