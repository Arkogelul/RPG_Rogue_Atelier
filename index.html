Download the installer Versions

  1. Run the installer. If Windows blocks it: "More info" → "Run anyway".
  2. If it asks for a GitHub token: follow its link (repository RPG_Rogue_Art, Contents: Read-only), paste the token.
  3. Restart Aseprite.
  4. Open "RPG Rogue Preview" (desktop shortcut). It updates itself.
  5. Sending art: while the preview runs, an icon near the clock watches your files. Save in Aseprite → a notification offers to send; click it, tick the files, "Send". The site updates about a minute later. (Also: Start menu → "RPG Rogue Send art".)
